# cmslens

cmslens определяет, на какой CMS, конструкторе сайтов или веб-фреймворке
работает сайт. Он читает HTML страницы и заголовки ответа и сверяет их с
таблицей из 556 платформ: WordPress, Shopify, Drupal и Webflow, а также
многие платформы, распространённые на русскоязычных сайтах: 1С-Битрикс,
Tilda, MODX, InSales, NetCat, UMI.CMS, uCoz и Flexbe.

Это библиотека на Go и программа для командной строки, без зависимостей за
пределами стандартной библиотеки.

Попробовать в браузере: [armilen.ru/services/cms](https://www.armilen.ru/services/cms)
работает на cmslens.

```
$ cmslens wordpress.org tilda.cc 1c-bitrix.ru
wordpress.org	WordPress
tilda.cc	Tilda
1c-bitrix.ru	1C-Bitrix
```

## Установка

```
go install github.com/profax/cmslens/cmd/cmslens@latest
```

Готовые программы для Linux, macOS и Windows приложены к каждому
[выпуску](https://github.com/profax/cmslens/releases).

## Командная строка

```
cmslens [флаги] домен...
cmslens -file page.html
```

| Флаг | Что делает |
|---|---|
| `-json` | по одному объекту JSON на сайт вместо текста |
| `-file page.html` | определить по сохранённой странице, без обращения к сети |
| `-timeout 60s` | ограничение времени на один сайт |
| `-scraperapi-key KEY` | повторить через [ScraperAPI](https://www.scraperapi.com/) сайты, которые не пускают сканер (ключ берётся и из `$SCRAPERAPI_KEY`) |
| `-country us` | код страны для ScraperAPI, если сайт отвечает только посетителям из своей страны |
| `-lang ru-RU` | какой `Accept-Language` отправлять |

Код выхода 1, если хотя бы один сайт просканировать не удалось.

## Библиотека

```go
import "github.com/profax/cmslens"

// Загрузить сайт и определить платформу.
res, err := cmslens.Scan(ctx, "https://example.com/some/page", cmslens.Options{})
fmt.Println(res.Detected) // [Next.js WordPress]

// Или определить по уже загруженной странице.
names := cmslens.Detect(html, resp.Header)
```

`Scan` принимает адрес страницы или просто имя сайта. В результате есть поле
`Status`: `ok` либо `cloudflare`, если на пути стояла страница защиты от
ботов и пройти её не удалось. `errors.Is(err, cmslens.ErrNoSuchHost)`
отличает опечатку в имени от сайта, который не ответил.

## Как устроено определение

У каждой платформы есть признаки с весами в теле страницы (пути к файлам,
метатег generator, встроенные скрипты) и в заголовках ответа (куки,
`x-powered-by`). Заголовок весит больше разметки: подделать его труднее.
Побеждает платформа с наибольшей суммой, и сверху действуют три правила:

- **У сайта один движок.** Побеждает только одна серверная платформа. Слой
  отображения вроде Next.js, Nuxt или Astro показывается рядом с ней, так что
  сайт с отдельным фронтендом получается `[Next.js WordPress]`.
- **По одному слабому признаку ответа нет.** Сумма меньше 1 ответа не даёт.
- **Короткие фрагменты ищутся с границы слова.** Иначе `evo-` найдётся внутри
  транслитерации `derevo-alyuminievaya`, и сайту припишется движок, на
  котором он не работает. Тест проверяет это для каждого признака.

Все признаки тела ищутся за один проход алгоритма Aho-Corasick, а
регулярное выражение запускается только на тех страницах, где нашлись все
его буквальные части. Новые платформы почти не меняют стоимость сканирования.

Комментарии в [`signatures.go`](signatures.go) объясняют для многих записей,
какая ложная находка на настоящем сайте определила вид признака.

## Безопасность

`Scan` рассчитан на работу на сервере с адресами, которые вводят
пользователи. Каждое соединение проходит через проверку того IP-адреса, к
которому открывается сокет, а не только имени: частные сети, петлевые и
локальные адреса и адрес метаданных облака (`169.254.169.254`) запрещены на
каждом перенаправлении и на каждом запасном адресе. Ответ ограничен 5 МБ,
перенаправлений не больше 5, прокси из окружения не используются.

## Как добавить платформу

1. Добавьте запись в `cmsSignatures` в [`signatures.go`](signatures.go).
   Лучше брать признаки, которые оставляет сама платформа (адрес её CDN,
   generator, куки), а не её название: его упоминают и другие сайты.
2. Если платформа определилась на настоящем сайте неверно, добавьте
   урезанную разметку тестом в [`falsepositive_test.go`](falsepositive_test.go).
3. Проверьте всю таблицу на живых сайтах:

   ```
   testdata/corpus.sh /tmp/corpus
   CMSLENS_CORPUS=/tmp/corpus go test -count=1 -run TestCorpus -v .
   ```

   В [`testdata/corpus.tsv`](testdata/corpus.tsv) около 2 900 общедоступных
   сайтов с ожидаемыми ответами. Сайты отвечают по-разному в зависимости от
   того, откуда их спрашивают, поэтому часть расхождений может идти от сети, а
   не от таблицы.
